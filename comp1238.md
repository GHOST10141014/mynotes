## Week 1 - Information Storage and History
- History of information storage included ledgers, tables, and physical typewriters before computers existed.
- We inherited a lot of terminology from physical typesetting and early font systems.

## Week 2 - Representation in Computers
- Computer memory relies on a distinction between short-term RAM and persistent storage.
- Text and characters are represented in computer memory using ASCII encoding and binary files.

## Week 3 - Structure of Text
- Text files rely on structure defined by punctuation, whitespace, line breaks, and escaping special characters.
- Structured and semistructured data can be represented as text using formats like MarkDown, HTML, and JSON.

## Week 4 - Manipulating Text
- Efficient text manipulation involves touch-typing, text editors, and keyboard shortcuts.
- Searching through text can be done effectively using wildcards and the basics of regular expressions (regexp).

## Week 5 - Text-Based Communication with the Computer
- The Command Line Interface (CLI) provides historical value for interacting directly with systems.
- Tools like SSH act as a near-universal remote control, alongside powerful CLI tools like grep and tmux.
